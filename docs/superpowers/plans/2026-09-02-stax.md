# STAX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Base Mini App that lets anyone build, value, save onchain, and set alerts on baskets of Coinbase tokenized stocks (B20), generating real onchain interactions from wallet `0x1dee`.

**Architecture:** Next.js (App Router) front-end using MiniKit + OnchainKit + wagmi/viem; a custody-free `BasketRegistry` Solidity contract on Base mainnet holds baskets/alerts; a shared read layer prices B20 tokens via Chainlink feeds (multiplier + staleness aware). Save/alert txs are the real interactions; buy/execute is gated on eligibility.

**Tech Stack:** Next.js 15, TypeScript, `@coinbase/onchainkit` (incl. MiniKit), wagmi, viem, Tailwind, Motion (one animation engine), Solidity + base-foundry (base-forge/base-anvil, WSL), Vercel.

**Spec:** `docs/superpowers/specs/2026-09-02-stax-design.md`
